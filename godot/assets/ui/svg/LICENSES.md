## How the game uses them

- The SVGs are **sources**. Godot imports SVG (ThorVG), but the lane pre-rasterises everything the OS, HUD and map
  need into `assets/ui/osui/` (white glyphs at 24/32/48/96 px, tinted in code), so no runtime SVG import settings are
  needed. If B loads an SVG directly, set the import scale so the texture is at least the display size in pixels.
- Lane-made art (app icons, HUD icon set, components, map markers) is original work generated by
  `tools/ui_art/osui/*.py`; Material Symbols paths are used inside a few of them (Phone, store glyphs, QS, settings
  rows). Map POI markers wrap Maki/Temaki glyphs (CC0) in lane-made category discs.
- Suggested credits line (Settings > About > Open-source licences): "Icons: Material Symbols (Google, Apache-2.0),
  Lucide (ISC), Tabler Icons (MIT), Phosphor Icons (MIT), Maki (Mapbox, CC0), Temaki (CC0). Fonts: Roboto
  (Apache-2.0), Roboto Mono (OFL-1.1)."
