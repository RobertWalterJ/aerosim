# AeroSim tablet UI kit (art for docs/CLAUDE-TABLET-UI.md)

All art is generated by `godot/tools/ui_art/build_all.py` (Python + Pillow + numpy; about 5 minutes). Edit the generator, not the PNGs.
Every PNG is RGBA. Nothing in the game loads these yet: the code on lane/notify still draws icons and dials itself
(`game/tablet_icon.gd`, `game/tablet_dial.gd`), so wiring is a separate small change.

## Layout and names (file names match the brief exactly)
- `icons/icon_<app>.png` 512 px composite tile (dronebudz, vidtube, photos, jobs, casebook, facade, settings, recents, weather, camera, home, phone). Exports in `icons/128/`, `icons/64/`, `icons/44/`, each rendered natively (not shrunk).
- `icons/layers/icon_<app>_bg.png` (full bleed) and `_fg.png` (art inside the 66 percent safe zone, checked by the generator) for adaptive masks.
- `icons/mono/[size/]icon_<app>_mono.png` white-on-alpha notification-shade versions (512, 128, 64, 44).
- `dials/dial_wind_face.png`, `dial_battery_face.png`, `dial_needle_wind.png`, `dial_needle_battery.png` (512; needles point up from the exact centre, rotate about (256,256)), `dial_battery_fill.png` (+ `_amber`, `_rust`): the 100 percent arc, reveal it with a radial TextureProgressBar. Arc sweep matches the old code: start 150 deg, 240 deg clockwise, centre (256,256), radius 176, width 32. Face leaves the middle clear for the live number.
- `weather/weather_<sun|cloud|rain|storm|fog|snow|wind|moon>.png` 512, plus `weather/128|64|44/`; `weather/widget_weather_face.png` is a 4 x 2 atlas of 256 px cells in that order.
- `status/128|64/status_<wifi|signal|battery|notification|search>.png` cream, `_brass` variants, `search_mic[_brass].png`; `status/badge_dot.png` (64), `status/32/badge_dot.png`, `status/badge_unread.png` (96 x 64 pill, number goes on top).
- `controls/` `switch_on` / `switch_off` (104 x 64), `switch_knob` (+ `_on` brass, 64), `slider_track` / `slider_fill` (256 x 64, groove 12 px high, stretch margins 32 left and right), `slider_knob`, `button_primary|ghost|card` (+ `_pressed`, 192 x 96, nine-patch margins 32 on all sides), `radio_on|off`, `check_on|off|mixed` (64), `search_pill` (640 x 96, margins 48).
- `frame/tablet_frame_1280x720.png`, `_1920x1080`, `_2560x1440`: 16:9 bezel overlay, fully transparent in the screen area, rounded corners, camera and speaker slot at top centre. Bezel is 2.4 percent of height.
- `polish/` `page_dot_on|off` (32), `dock_tray` (512 x 128, margins 44), `wallpaper_vignette` (1920 x 1080 warm umber, transparent centre).

## Rules kept
Baked shadows never exceed 8 px (the generator asserts it). No Android, Google or social marks; VidTube is a fictional play-in-frame with a progress bar. Palette from `docs/UI-STYLE.md` plus tile depths listed in `tools/ui_art/gen_icons.py`.

## Fonts
Only one font appears in the art (compass letters, gauge E/F, and the preview sheets): **Inter** (variable), SIL Open Font License 1.1, (c) The Inter Project Authors, https://rsms.me/inter/. Copy bundled at `tools/ui_art/fonts/Inter.woff2` (taken from Blender 4.2.3's data files). OFL permits embedding and bundling.
